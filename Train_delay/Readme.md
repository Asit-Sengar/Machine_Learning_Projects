# 🚆 Train Delay Predictor

### Find the train expected to arrive with the least delay.

This project aims to predict delays for multiple train options and recommend
the one with the **lowest estimated delay**.

## ✨ How it works

1. **Compare options** — provide the trains being considered for a journey.
2. **Predict delays** — estimate the expected delay for each train using
   relevant journey details and historical delay data.
3. **Choose a train** — rank the options and highlight the one with the
   lowest predicted delay.

The goal is to make train comparisons clearer and help passengers make more
informed travel choices. Actual delays can differ from predictions due to
changing railway and operating conditions.
